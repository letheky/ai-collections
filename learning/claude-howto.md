## Tóm tắt

Đây là hướng dẫn học Claude Code theo lộ trình, có hình minh họa và **template copy-paste được**.
Tác giả là Lương Nguyễn (`luongnv89`). Giấy phép **MIT**, phiên bản 2.1.296.
Có **bản tiếng Việt** ở thư mục `vi/`, cùng các bản tiếng Trung, Ukraina, Nhật.

## Nhận xét

- **Rất hợp làm tài liệu onboarding** cho team mới dùng Claude Code, nhất là khi có bản tiếng Việt.
- **Claude Code cập nhật rất nhanh.** Một số chi tiết có thể lệch phiên bản; khi có mâu thuẫn thì đối chiếu với docs chính thức tại code.claude.com.
- **Đọc trước khi copy:** các template hook và MCP có thể chạy lệnh trên máy.
